# 06 · 交付前自检清单

> 每次交付前逐条打勾。少一条都可能被退回或被打低分。

## A. 模型

- [ ] 单位正确（厘米），尺寸与设定一致（152.5 × 144.8 × 333.9 cm）
- [ ] 原点在脚底中心，落地为 Z=0
- [ ] 没有非流形边（Non-manifold）
- [ ] 没有重叠面 / 内部穿插面（或已确认可接受）
- [ ] 法线方向正确（无黑面、无翻面）
- [ ] 多余对象已删除、合并为单一 Mesh
- [ ] 材质槽数量与贴图集数量一致（本项目 1 个）
- [ ] 面数在目标范围（本项目 126,748 tris）

## B. UV

- [ ] 只有 1 个 UV Set，没有历史遗留 UV
- [ ] 没有重叠（Overlapping）UV
- [ ] 棋盘格检查通过：所有方块在 3D 视图中为正方形
- [ ] 接缝不在正面可见区域
- [ ] 打包留边 ≥ 1%
- [ ] 空间利用率 ≥ 70%（本项目 82.4%）

## C. 贴图

- [ ] PBR 贴图齐全（本项目：BaseColor / Roughness / Metallic / Normal 四张；Height 为空通道已删除）
- [ ] 分辨率一致（4K）
- [ ] 法线为 OpenGL 或 DirectX 规范明确（引擎要求不同）
- [ ] Padding / Dilation 已开（本项目 ×16）
- [ ] 接缝处无可见色差
- [ ] 贴图命名符合规范（`robot_a2_BaseColor.png`）
- [ ] 数据通道（Roughness / Metallic / Normal）在引擎里设为 Non-Color

## D. 展示

- [ ] Hero 渲染 1 张（≥1600 px）
- [ ] 三视图 3 张（正交）
- [ ] 细节特写 ≥ 3 张
- [ ] 线框图 ≥ 1 张
- [ ] UV 布局图 1 张
- [ ] 成品材质渲染 ≥ 3 张
- [ ] 所有图统一背景与光照

- [ ] 没有 `.mp4`、`.spp.painter_lock`、`autosave`、`.max.bak`
- [ ] 没有学号 / 真实姓名的目录名
