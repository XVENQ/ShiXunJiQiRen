# 03 · UV 展开笔记

工具：RizomUV Virtual Spaces 2022.0（汉化版）

## 一、为什么不用 Max 自带的 Unwrap UVW

RizomUV 的强项是**打包（Pack）**。同样的 UV 岛数量，RizomUV 的自动打包通常能多榨出 10%–15% 的空间利用率。对这个模型：

| 指标 | 结果 |
| --- | --- |
| UV Set 数量 | 1 |
| UV 岛数量 | 333 |
| 0–1 空间利用率 | **82.4%** |
| 接缝策略 | 结构分件线优先 |

## 二、作业顺序

```
Max 导出选中模型 → RizomUV 导入 → 切缝（Seams）→ 展平（Unfold）
→ 检查拉伸（棋盘格）→ 打包（Pack）→ 导出 OBJ → 进 Painter
```

## 三、切缝的四条规则

1. **接缝藏在结构线**：分件缝、内凹槽、螺孔边缘。做硬表面的天然优势——零件多，缝有的是地方藏。
2. **正面大平面绝不切断**：舱体侧板、腿部护板这些大面积区域，一旦中间切一刀，材质绘制时会出现无法对齐的接缝。
3. **按材质分区**：同色/同材质的零件尽量归入同一片 UV 区域，Painter 里可以整片填充，省时间。
4. **圆柱类零件只切一条**：天线、软管、关节轴切一条母线，展开后是长条，避免拉伸。

## 四、拉伸检查（最容易被跳过的步骤）

导出前必须在 RizomUV 里贴棋盘格检查，标准只有一条：

> **每个方块在 3D 视图里必须是正方形，横竖边长相等。**

- 被拉长 → 展开不足，UV 面积小于实际面积
- 被压扁 → 顺时针/逆时针的翻面或重叠

任何一处拉伸，Painter 画出来的材质精度都会不一致。这是 UV 阶段唯一的硬指标。

## 五、打包（Pack）参数思路

- 单张 0–1，不做 UDIM。理由：这是游戏资产，单套贴图更利于引擎管理和显存控制。
- 留边（Padding / Margin）：约 1%–2%，防止 mipmap 时接缝渗色。
- 分组（Group）：按材质分组打包，同组内部紧密排列，组间留空隙。
- 旋转允许：小零件允许 90° 旋转，能多塞进去不少。

最终 333 个岛、82.4% 利用率。硬表面一般 70% 以上就可用，80%+ 属于比较紧的水平。

## 六、常见错误

| 错误 | 现象 | 后果 |
| --- | --- | --- |
| 忘记删历史 UV | 导入 Painter 后 UV 重叠 | 材质错位、闪烁 |
| 接缝放在正面 | 一条明显的直线 | 材质无法修复，只能重切 |
| 不做棋盘格检查 | 局部花纹被拉长 | 贴图精度不均，肉眼可见 |
| 打包不留边 | mipmap 后接缝渗色 | 远景出现彩色脏边 |
| 岛太碎（上千个） | 打包效率暴跌 | 利用率掉到 50% 以下 |
