## 逐阶段说明

### 1. 建模（3ds Max 2022）

**顺序：大形体 → 结构 → 细节 → 卡线。**

- 大形体拆成 5 个模块推进：身体、天线、手臂、腿部、脸部。分开建的好处是单个模块改形不影响其他部件。
- 结构阶段做「减法」：把方舱切出台阶、凹槽、面板缝，形成硬表面的层次。
- 细节阶段加螺栓、卡箍、线管、关节轴。
- 卡线（Support Loop）放在最后统一处理，因为倒角加上去之后才能判断哪里需要支撑线。
- 迭代过程中产生了 3 个版本的 `机器人.max`（16.3 MB / 15.3 MB）和多个中间 OBJ，**版本靠文件名区分**——这是集训条件下的土办法，规范做法见 `05-publishing-guide.md` 的版本管理部分。

**当时的判断：** 硬表面最容易犯的错是把倒角当装饰。倒角的作用是给高光一条过渡带，宽度要跟物体尺度匹配（3.3 m 的机体，1–2 cm 的倒角才读得出来）。

### 2. UV（RizomUV VS RS 2022.0）

3ds Max 只负责「选中 → 导出 OBJ」，切割和展开全在 RizomUV 里做，原因是 RizomUV 的打包效率远高于 Max 自带的 Unwrap UVW。

- **切缝原则**：接缝走结构线（分件缝、内凹槽、背面中线），正面大平面绝不切断。
- **展开**：Auto Seams 起草 → Unfold → 用棋盘格贴图检查拉伸。
- **打包**：单张 0–1，最终 333 个岛、利用率 82.4%。
- **回导**：RizomUV 导出 OBJ，进 Painter。

**当时的判断：** UV 岛数量不是越少越好。硬表面零件多、结构碎，333 个岛是合理的；关键是**拉伸是否均匀**和**空间是否吃满**。82.4% 的利用率对硬表面来说属于好成绩（一般 70% 以上就可用）。

### 3. 材质（Substance 3D Painter）

**顺序：大色块 → 材质区分 → 磨损逻辑 → 贴纸标识 → 接缝对齐。**

- 填充层（Fill Layer）先铺 5 类材质：主装甲、副装甲、关节金属、橡胶、发光件。
- 磨损按物理逻辑分层：边缘（Edge Wear）→ 凹陷积灰（Dirt）→ 划痕（Scratches）→ 局部锈迹。
- 贴纸用外部 PNG 做 decal 图层，边缘做褪色和破损。
- 接缝处跨岛绘制，避免出一条亮线。

产出 `jiqiren-a-2.spp`（168 MB）。工程里保留了完整图层栈，后续改色不需要重画。

### 4. 优化与导出

- 合并为单一 Mesh，最终 63,612 verts / 126,748 tris。
- 单位设为厘米，尺寸 152.5 × 144.8 × 333.9 cm。
- 导出 OBJ（带 MTL）+ FBX（三份，用于不同用途）。
- 提交时按 `学号` 命名文件夹——**这是课程要求，作品集里必须改掉**（见 `05-publishing-guide.md`）。

## 流程上的问题（复盘）

1. **文件版本靠文件名**：`jiqiren-uv-2w7a` / `2w8a` / `2w9a` 这类名字三天后自己都看不懂。规范做法是 `assetname_stage_vNNN`。
2. **没有中途出图**：整个流程只在最后截了一张 361×230 的视口图。作品集需要**每个阶段都有图**，这是本次整理补渲染的原因。
3. **贴图交付滞后**：`.spp` 交付时只有工程，4K PBR 是整理作品集时才补导出的。规范做法是**交付即导出**，工程和贴图一起交。
4. **没有做 LOD**：单一精度交付，进引擎后要靠引擎自动减面。下一版补 LOD1/LOD2。
