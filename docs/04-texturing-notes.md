# 04 · 贴图笔记（Substance 3D Painter）

## 一、图层顺序

```
① 基础材质分区（Fill Layer + Mask）
② 大色块 / 涂装
③ 边缘磨损（Edge Wear）
④ 凹陷积灰（Dirt / Cavity）
⑤ 划痕与刮擦（Scratches）
⑥ 贴纸与标识（Decal）
⑦ 整体调节层（对比度 / 色偏）
```

顺序的关键：**磨损必须在涂装之后**。先磨损后涂装，等于把磨损盖掉了。

## 二、五类材质分区

| 分区 | 材质特征 | 常用参数 |
| --- | --- | --- |
| 主装甲 | 喷漆金属，中等粗糙 | Metallic 0.8–0.9 / Roughness 0.45 |
| 副装甲 | 深色喷漆，微光泽 | Metallic 0.7 / Roughness 0.55 |
| 关节金属 | 裸露金属，高反射 | Metallic 1.0 / Roughness 0.25–0.35 |
| 橡胶件 | 非金属，哑光 | Metallic 0 / Roughness 0.8 |
| 发光件 | 自发光 | Emission + 低 Roughness |

先定这五类，再往图层里加细节。跳过这一步直接画，结果一定是「到处都一样脏」。

## 三、磨损的物理逻辑

硬表面最容易画错的地方是「随机撒脏」。正确做法是按物体结构分布：

1. **边缘磨损**：凸出的边、倒角处，用 Curvature Map 生成遮罩，再手动刷掉不合理的位置。
2. **凹陷积灰**：凹槽、缝隙、螺栓周围，用 AO / Position 生成。
3. **划痕**：方向要统一（同一台机器的划痕来自同一个运动方向），不能随机四散。
4. **锈迹/流痕**：从固定点向下流，跟着重力走。

## 四、贴纸处理

- 用外部 PNG 做 Decal（投影）图层，不要直接平铺。
- 贴纸边缘加磨损：Alpha 边缘做破损，再叠一层轻微脏迹。
- 贴纸的粗糙度和底材不同（贴纸是纸质/乙烯基，比金属哑），单独给 Roughness。
- 贴纸位置避开 UV 接缝，否则会被切断。

## 五、接缝对齐

UV 接缝处是最容易出问题的地方：两侧颜色/粗糙度不一致，远景会看到一条线。

处理方法：
1. 用镜像绘制（Symmetry）跨岛对齐；
2. 或者在接缝处加一层同参数的 Fill Layer，把接缝压进整体色里；
3. 最省事的做法是**在 UV 阶段就把接缝藏进结构线**——这也是 `03-uv-notes.md` 里第一条规则的原因。

## 六、导出贴图（已完成）

`.spp` → `File → Export Textures`（`Ctrl + Shift + E`），实际使用的参数：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 输出模板 | `PBR Metallic Roughness` | 命名规范，直出引擎可用通道 |
| 分辨率 | 4096 × 4096 | 固定值，不跟随纹理集 |
| 文件格式 | PNG | 法线必须 PNG，有损格式会破坏向量 |
| 填充 | 无限膨胀 × 16 | 默认 1 会渗色，16 是安全值 |

导出结果 5 张，落到 `assets/textures/`：

```
robot_a2_BaseColor.png   4096²  sRGB      军绿/锈黄涂装 + 青绿面板 + 贴纸
robot_a2_Roughness.png   4096²  Linear   均值 0.81，整体哑光
robot_a2_Metallic.png    4096²  Linear   均值 0.13，仅关节/管线为金属
robot_a2_Normal.png      4096²  Linear   OpenGL 规范
robot_a2_Height.png      ——      ——     全图纯白，空通道，已删除
```

**Height 为什么是空的：** 导出后检测到均值 255、标准差 0，说明工程里没有绘制高度信息。这不是导出出错，而是本来就没画。需要凹凸时用 Normal 即可。

**渲染验证：** Blender 里用 Principled BSDF 接四张图（BaseColor→sRGB，其余→Non-Color），渲染确认 UV 与贴图完全匹配，说明从 RizomUV 到 Painter 的 UV 传递没有断裂。

## 七、本次的不足

1. **没有画高度**：Height 通道为空，表面凹凸全靠 Normal 伪凹凸，近景看缺少真实的边缘起伏。
2. **图层命名不规范**：工程里图层叫「图层 1」「填充 3」，后期维护成本高。规范做法是 `M_Armor_Paint_Dark` 这种带材质前缀的命名。
3. **只有一套 4K 贴图**：没有做 2K 降级版本，进移动端需要引擎侧压缩。
