# 02 · 硬表面建模笔记

工具：3ds Max 2022

## 一、建模顺序

```
大形体（Blockout）→ 结构切分 → 细节零件 → 倒角 → 卡线 → 检查
```

顺序不能乱。先倒角再结构调整，等于每次改形状都要重做倒角。

## 二、硬表面的三条原则

### 1. 倒角是光的过渡带，不是装饰

3.3 m 高的机体，倒角宽度 1–2 cm（约模型高度的 0.3%–0.6%）才读得出高光。倒角太窄，远处看边缘像纸片；太宽，硬表面变成塑料圆角。

所有可见外轮廓边至少 **1 段**倒角，主结构边 **2 段**（Chamfer 的 Segments）。

### 2. 卡线决定平滑后的形状

倒角两侧加支撑线（Support Loop）。没有支撑线，细分/平滑后倒角会被拉成一个大圆角，边缘识别度全丢。

判断方法：把模型切到平滑预览，看边缘高光是否还是一条清晰亮线。糊了，就是支撑线不够或太远。

### 3. 平面疏、曲面密

硬表面不需要均匀布线。大平面（舱体侧板）用最少的线；转折处、曲面（天线、圆形脸盘、关节轴）加密。

这样做的直接收益：面数花在能看见的地方，后期减面时平面区域也不会崩。

## 三、模型结构

40 个独立部件合并为一个 Mesh，主要模块：

| 模块 | 部件类型 | 说明 |
| --- | --- | --- |
| 身体舱体 | Box 起手 | 主装甲板 + 内凹槽 + 检修口 |
| 头部 | Box + Cylinder | 圆形脸盘（唯一「拟人」元素）+ 双侧天线 |
| 手臂 | Cylinder + 软管 | 单段式，无肘关节，靠软管表现柔性 |
| 腿部 | Box + Cylinder | 分两段，末端为三爪脚 |
| 细节件 | Cylinder / Torus | 螺栓、卡箍、线管接口、关节轴 |

**为什么部件化：** 40 个独立对象，改一个螺栓不影响主体；代价是合并后容易有内部穿插面（这也是线框渲染出现尖刺的原因，见 `04-texturing-notes.md` 的排查记录）。

## 四、尺寸与单位

- 单位：厘米（Max 系统单位与显示单位统一）
- 最终尺寸：152.5 × 144.8 × 333.9 cm
- 建模原点放在脚底中心，便于进引擎后落地对齐

**踩坑：** OBJ 导出后坐标保留了 Max 的世界坐标偏移（X ≈ -29000, Y ≈ 31500），导入 Blender 后模型跑到画面外。解决方式是导入后按包围盒重新居中，不是手动挪。

## 五、本次的不足

1. **内部穿插面没清理**：40 个部件互相插入，合并后内部有大量隐藏面。规范做法是布尔或删除内部面，能省 15%–25% 面数。
2. **没有做 UV 前的三角化检查**：部分区域有细长三角面，展 UV 时容易拉伸。
3. **拓扑没有为动画留循环线**：这是静态资产，如果要绑骨，关节处需要重做布线。
