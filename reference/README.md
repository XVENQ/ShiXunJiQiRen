## 关于「参考」的边界

- **参考剪影和结构语言** → 属于正常的学习行为，任何 3D 从业者都这么干。
- **照抄具体设计、直接描图建模** → 属于抄袭，作品集里不要放。
- 本项目参考的是**机甲/巡检机器人的通用视觉语言**（方舱 + 外露管线 + 双天线），不是某一张具体的画。

## 如果想自己复现

不建议照抄参考图。更有效的练习路径：

1. 抄一张参考图的**比例关系**（用三视图对齐法），不抄细节；
2. 用自己的结构逻辑重新设计分件；
3. 细节（螺栓、管线、接口）按真实机械逻辑摆放，而不是按画面好看摆放。
