# 模型文件说明（Models）

## 文件清单

| 文件 | 大小 | 格式 | 说明 |
| --- | --- | --- | --- |
| `robot_a2_hardsurface.obj` | 12 MB | Wavefront OBJ | **主资产**。63,612 verts / 126,748 tris，含 UV，单位为厘米 |
| `robot_a2_hardsurface.mtl` | 378 B | MTL | 材质定义（占位色，不含贴图路径） |

## 重要说明

### 1. 这些文件不含贴图

OBJ/FBX 里**没有**材质贴图引用。PBR 贴图需要单独导出（见 `../textures/README.md`），或从 `.spp` 工程重新导出。

导入后模型会显示为灰模——这是正常现象，不是文件损坏。

### 2. 坐标与朝向

- 原始导出文件保留了 3ds Max 的世界坐标偏移（X ≈ -29000, Y ≈ 31500）。
- 导入 Blender 时需重新居中，参数：`forward_axis='NEGATIVE_Z', up_axis='Y'`，然后按包围盒居中到原点。
- 正面朝 **+X**，头顶朝 **+Z**。
- 尺寸：152.5 × 144.8 × 333.9 cm（约 3.3 m 高）。

### 3. 网格规格

| 指标 | 数值 |
| --- | --- |
| 顶点 | 63,612 |
| 三角面 | 126,748 |
| 四边面 | 0（已完全三角化） |
| UV Set | 1（`UVMap`） |
| 材质槽 | 1 |
| 部件数（原始） | 40（已合并为单一 Mesh） |

**注意：** 导出时已被三角化。如果要修改拓扑，建议从 `.max` 源工程改，不要在三角化网格上改。

### 4. 未包含的内容

- 没有 LOD
- 没有骨骼/绑定
- 没有碰撞体

这是静态展示资产，不是可动画的角色资产。

## 导入检查清单

```
□ 单位确认为厘米（FBX 导入时检查 Scale Factor）
□ 模型落地（最低点 Z = 0）
□ 法线朝向正确
□ UV 未重叠
□ 材质槽数量 = 1
```
